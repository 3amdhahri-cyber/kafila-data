# kafila-data

Offline mosque data for the Kafila app, one file per country (`mosques/CC.json`, rows `[lat, lon, name, address]`) and `mosques/index.json`.
Built from OpenStreetMap by `tool/generate.py` (daily job; each country is refreshed every 30 days).
